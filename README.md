## 🎯 About This Repository

This repository contains the practical implementation of various algorithms covered in the Design & Analysis of Algorithms Laboratory.

The main objective of this laboratory is to understand algorithm design techniques, implement different algorithms using C++, analyze their time and space complexity, and evaluate their performance through practical experiments.

The repository is organized into seven units according to the laboratory syllabus.

## 📖 Unit 1 – Introduction to Algorithms & Performance Analysis

**Course Outcome: CO1**

Experiments include:

- Basic operations on arrays.
- Iterative Binary Search.
- Recursive Binary Search.
- Best, average, and worst-case complexity analysis.
- Execution time measurement for different input sizes.
- Storing experimental results and generating performance graphs.
- Algorithm Performance Analyzer.

## 📖 Unit 2 – Divide and Conquer

Experiments include:

- Binary Search using Divide and Conquer.
- Maximum and Minimum using Divide and Conquer.
- Merge Sort.
- Quick Sort.
- Heap Sort.
- Strassen's Matrix Multiplication.
- Sorting Performance Comparison System.

## 📖 Unit 3 – Greedy Method

Experiments include:

- Fractional Knapsack.
- Job Sequencing with Deadlines.
- Minimum Cost Spanning Tree using Prim's Algorithm.
- Minimum Cost Spanning Tree using Kruskal's Algorithm.
- Comparison of Prim's and Kruskal's Algorithms.
- Minimum-Cost Network Design System.

## 📖 Unit 4 – Dynamic Programming

Experiments include:

- Fibonacci using Recursion.
- Fibonacci using Memoization.
- 0/1 Knapsack using Dynamic Programming.
- Multistage Graph.
- All-Pairs Shortest Path using Floyd-Warshall.
- Single-Source Shortest Path.
- Traveling Salesperson Problem using Dynamic Programming.
- Route Optimization System.

## 📖 Unit 5 – Traversal and Search

Experiments include:

**Tree Experiments**
- Binary Tree Creation.
- Preorder Traversal.
- Inorder Traversal.
- Postorder Traversal.
- Recursive and Iterative Tree Traversals.

**Graph Experiments**
- Graph using Adjacency Matrix.
- Graph using Adjacency List.
- Breadth First Search (BFS).
- Depth First Search (DFS).
- Recursive DFS.
- Iterative DFS.
- Graph Exploration / Network Traversal System.

## 📖 Unit 6 – Backtracking

Experiments include:

- General Backtracking Technique.
- 4-Queens Problem.
- 8-Queens Problem.
- N-Queens Problem.
- Sum of Subsets.
- Constraint Satisfaction Solver.

**Advanced Options**
- Sudoku Solver.
- Graph Coloring.
- N-Queens Solver.

## 📖 Unit 7 – NP-Hard and NP-Complete

Experiments include:

- Demonstration of a problem using Exhaustive Search.
- 0/1 Knapsack using Branch and Bound.
- Traveling Salesperson Problem using Branch and Bound.
- Comparison of 0/1 Knapsack using Dynamic Programming and Branch and Bound.
- Comparison of TSP using Dynamic Programming and Branch and Bound.
- Optimization Algorithm Comparison System.
